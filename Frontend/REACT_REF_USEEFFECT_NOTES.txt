React Notes: ref={scrollRef}, useEffect cleanup, and what happens under the hood

1) What ref={scrollRef} means
- In React, ref lets you access a real DOM element directly.
- You usually create it with:
  const scrollRef = useRef(null);
- Then attach it in JSX:
  <div ref={scrollRef} />
- After render, React puts the DOM node into scrollRef.current.
- You can then read or control it, for example:
  scrollRef.current.scrollLeft
  scrollRef.current.clientWidth
  scrollRef.current.scrollBy(...)

2) Common issue in this component
- If scrollRef is used but never created with useRef, it will fail.
- Also, if useEffect has no dependency array, it runs after every render.
- That can attach multiple scroll listeners unless you clean up correctly.

3) Correct effect pattern
useEffect(() => {
  const container = scrollRef.current;
  if (!container) return;

  container.addEventListener("scroll", updateScrollButton);
  updateScrollButton();

  return () => container.removeEventListener("scroll", updateScrollButton);
}, []);

4) Why cleanup is returned as a callback function
- React expects useEffect to return either:
  - nothing, or
  - a cleanup function
- This is correct:
  return () => container.removeEventListener("scroll", updateScrollButton);
- React stores that function and calls it later (before re-run or unmount).

5) What happens if you do this instead
  return container.removeEventListener("scroll", updateScrollButton);
- removeEventListener runs immediately during effect setup.
- The listener is removed right away.
- The returned value is undefined, so React has no cleanup function saved.

6) Under-the-hood timeline
- Render happens.
- React commits UI to DOM.
- React runs effect setup code.
- Listener is attached.
- Returned function is stored by React as cleanup for this effect run.
- Later, before next effect run or unmount, React calls stored cleanup.
- Listener is removed safely, avoiding duplicates and leaks.

7) Mental model
- Setup: attach listener now.
- Returned function: detach listener later, when this effect run is old.
